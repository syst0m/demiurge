# Routine — REDACTED REDACTED recovery loop

Status: **proposed for the user to approve** (not scheduled, not started).

## What it is
A weekly recurring loop that runs the REDACTED REDACTED recovery protocol (`protocols/auadhd-REDACTED/protocol.md`) between professional appointments. It is the durable, rung-3 loop: plan -> run -> review, repeatable by the operator without me.

## The loop
- **Sunday (~45 min): Plan.** Energy-ruler baseline (0-5); must-do slots against capacity + 1.5-hour buffer; dex timing per matrix; one optional commitment max; trauma session scheduled; sleep target >=6.5h on >=5 nights.
- **Mon-Fri (~10 min/day): Run.** Energy ruler before and after; one grounding/reset break; dex timing; sensory block; trauma pacing; overcommitment guardrail; log energy, sleep, dex side-effects, overcommitment hours, crisis-gate events.
- **Friday (~45 min): Review.** Energy trend, side-effect severity, overcommitment hours, sleep; adjust next week's capacity (never the other way round). If a disrupted night, apply the buffer rule (R4: fixed wake, next-day target recovered, meds unchanged).

## Edge cases
- **Crash day (fatigue >=4):** minimum viable schedule + rest + no new med changes; sleep window protected.
- **Overcommitment temptation:** pre-commit capacity check; decline or defer (<=1 optional/day); pause 24h before accepting on FOMO/RSD.
- **Tier 0 crisis gate (any day):** self-harm, suicidal ideation, or severe/unstable medication reaction -> stop all self-management, escalate to professional emergency care; no coping technique as substitute.

## Escalation
- **Prescriber (call same day):** resting pulse >120, chest pain, palpitations, severe anxiety, paranoia, suicidal thoughts, seizure; sleep <6h for 2 nights; side-effects worsening; guardrails consistently breaking.
- **Trauma clinician (book soon):** triggers becoming frequent; body staying in alarm; acute dissociation feeling unsafe.
- **Emergency services / 988:** Tier 0 gate triggers.

## Numbers to report at the end of each review (the learning goal)
- No severe dex side-effect day on >=4 of 7 days.
- Sleep >=6.5h on >=5 nights/week.
- Zero overcommitment breaches.
- Zero crisis-gate events.

## Dependencies
- Prescriber who can adjust dexamphetamine and review timing/side-effects.
- Licensed trauma-informed clinician on a set schedule.
- The operator keeps the capacity log and the 1.5h buffer.
