# Glossary — git-lifecycle-guard

Terms used across the cleanup workflow and its harness wiring. No implementation details here.

**merged branch** — A local branch whose tip commit is an ancestor of `main` (or the repo's default branch). Eligible for deletion under rule 1 once old enough.

**stale worktree** — A git worktree whose branch is merged into `main`. Eligible for removal under rule 2.

**sign-off** — The written approval that authorizes a cleanup deletion. For merged branches, the merge commit on `main` is the sign-off. For unmerged branches and worktrees, an explicit `yes` from the operator; silence is not a yes.

**cleanup log** — Append-only record at `~/.demiurge/lifecycle-guard/cleanup.log`. Each line: `timestamp | repo | branch | tip-sha | sign-off | action`. Never rewritten wholesale.

**restore pointer** — The tip SHA logged with every deletion, allowing `git branch <name> <sha>` to resurrect a deleted branch.

**dump-before-delete** — Before a destructive worktree remove, uncommitted/untracked status is dumped to `--dump-dir`. Branch deletions are restorable via their logged tip SHA.

**staging** — Install scope where the canonical source is the only copy. Nothing is written to any harness. Recommended for T2 skills under Rule G-13.

**global** — Install scope where hooks reach every session that loads them. Refused for T2 skills under Rule G-13; requires operator override.

**check** — Read-only audit mode. Exits non-zero when any rule fails; blocks progress until work is complete.

**cleanup** — Sign-off-gated deletion mode. Dry-run unless `--apply`; always requires `--sign-off`.

**trifecta** — Private data + untrusted content + exfiltration vector. Two legs present (local git repos, remote refs); exfiltration absent (no network calls). No session split required.

**T2** — Trust tier: generated by Marcus, not yet G5-accepted. Default permissions: read only; must not be installed globally.
