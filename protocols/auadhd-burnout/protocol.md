# REDACTED Burnout Recovery Protocol

**Status:** working draft · target duration 12 weeks (stabilise → restore → process → protect)
**Not medical advice.** This protocol is informational self-management material; it replaces no professional care.

- **Dexamphetamine:** never start, stop, or change dose without the prescribing clinician. Report palpitations, chest pain, severe anxiety, paranoia, or suicidal thoughts immediately.
- **Emotional trauma:** engage a licensed trauma-informed clinician for processing. Self-management is not treatment for trauma.
- Share this with a clinician where possible and use it alongside, not instead of, care.

## 1. Altitude ladder (outcome)

1. **Understand, don't fill in** — map the depletion cycle before changing anything.
2. **Get to the decisions** — the three decisions that most reduce harm: medication timing, sleep priority, capacity-based planning.
3. **Replace the ritual** — a daily/weekly operating loop that catches problems earlier from the user's own history.

## 2. Depth — the expert's instruments (raw material first)

- Psychiatrist: review medication timing + side-effect management. [my judgement]
- Trauma clinician: sets pacing and grounding boundaries; scheduled, not improvised in crisis.
- OT: sensory diet + energy accounting.
- ADHD/executive-function coach: habit + accountability.
- Raw material: un-digested symptom log, sleep record, dex side-effect diary, capacity scores, trauma trigger list.

## 3. Range — read-only crew (findings only; no edits, no debate)

Clinical psychopharmacology, trauma-informed therapy, OT, ADHD coaching, peer support. Each returns findings only; none edits this protocol.

## 4. Daily Operating System — five modules

**M1. Energy ruler.** Self-rate 1–10 before and after each commitment and record it. [my judgement] baseline: 1–3 depleted, 4–6 usable, 7+ over-able. Use the shift, not the absolute.

**M2. Dex timing matrix.** [my judgement]

- R1: take dex after the first meal (food buffers absorption; reduces appetite suppression).
- R1: no dose after 15:00 — protects sleep and the evening window.
- Track daily: sleep hours, appetite, heart rate/BP if available, anxiety, irritability, crash severity (0–3 each).
- Red flags → stop and contact prescriber same day: resting pulse >120, chest pain, paranoia, suicidal thoughts.
- No "top up" outside prescribed timing; no caffeine stacking without the prescriber's OK.

**M3. Sensory diet.** [my judgement — OT practice]

- Quiet blocks: minimum 30 min/day with reduced input (noise-cancelling, lowered lighting).
- One dominant input at a time (one screen, one conversation, one task).
- Use the crash-day protocol (M6) when sensory load peaks instead of pushing through.

**M4. Trauma pacing.** [my judgement]

- R4: one 10-min grounding/reset break every day (5-4-3-2-1 or paced exhale).
- Processing happens with the clinician on a set schedule; never improvised in crisis.
- Safety plan on file: 2 safe contacts, warning signs, crisis line.

**M5. Overcommitment guardrail.** [my judgement]

- R6: at most one optional (non-essential) commitment per day.
- Pre-commitment rule: before accepting anything new, run the capacity check. If recovery blocks are fewer than 2/week, decline or defer.
- Capture-by-default: one trusted external system (calendar + task list); the brain is for thinking, not remembering.

## 5. Rules the held-out checks compose from (R1–R6)

- R1 med timing: dex after the first meal; no dose after 15:00.
- R2 sleep: target ≥6.5h with a fixed wake time.
- R3 capacity: must-do ≤16h/day + 1.5h buffer.
- R4 trauma pacing: one 10-min grounding/reset break every day.
- R5 crash day: fatigue ≥4 → minimum viable schedule + rest + NO new med changes.
- R6 overcommitment guardrail: ≤1 optional commitment per day.

## 6. Crash-day response (edge case — V6)

When fatigue ≥4 (energy ruler) or "brain fog + irritability + nothing done":

- Minimum viable schedule only (one must-do, one grounding break, rest).
- No new medication changes: no escalation, no skipped dose, no extra dose.
- Sleep window protected; next day returns to the fixed wake time.
- [my judgement] a crash day is a signal, not a failure — review the prior day's dex timing, sleep, and load.

## 7. Overcommitment-temptation response (edge case — V6)

When a new offer arrives and capacity is full:

- Apply the guardrail: decline or defer (≤1 optional/day).
- Pre-written script: "I can't take this on right now; can we revisit in [time]*."
- If the temptation is strong (FOMO/RSD): pause 24h before accepting — the feeling is information, not a command.

## 8. Weekly cycle (plan → run → review)

- Plan (30 min): energy-ruler baseline, must-do slots, one optional commitment max, sleep target.
- Run: daily log (the five modules + R1–R6).
- Review (45 min, weekly, repeatable without the builder): what drained, what recovered; adjust next week's load; add a buffer rule so a disrupted night does not cascade.
- Burnout recurs within 2 weeks of a commitment? Treat overcommitment tolerance as the problem, not the task.

## 9. The numbers (target)

Learning goal first: identify the medication-timing + pacing combination that reduces the worst dex side-effects while keeping function.
Then the numbers: no severe side-effect day on ≥4 of 7 days; sleep ≥6.5h on ≥5 nights/week; zero overcommitment breaches; no crisis-gate events.

## 10. Escalations

- Tier 0 crisis gate: self-harm, suicidal ideation, or severe/unstable medication reaction → stop all self-management, escalate to professional emergency care, offer no coping technique as a substitute.
- Prescriber red flags: palpitations, chest pain, severe anxiety, paranoia, suicidal thoughts, seizure.
- Therapist red flags: acute dissociation that feels unsafe, self-harm urges.
